# 🐎 달리는 말 택시미터

**달리는 말 택시조합**의 택시미터. 운전하면 **진짜로 요금이 올라갑니다.** 아무 필요 없는데, 그러니까 재밌다.
아이폰 Safari에서 홈 화면에 추가해 앱처럼 쓰는 PWA입니다.

**▶ 실행: https://ik4utube.github.io/taximeter/**

## 기능

- **실제 서울 택시 요금** (2023.2.1 시행, 서울시)
  - 기본 1.6km 4,800원 · 131m당 100원 · 30초당 100원(15.72km/h 이하)
  - 심야할증 자동: 22–23시·02–04시 20%, 23–02시 40% / 시계외할증 20%(`할증` 버튼)
- **GPS 주행 측정** — 정확도 필터로 제자리 떨림 무시
- **달리는 말 애니메이션** — 머이브리지의 실제 연속 사진(1878) 11장을 실루엣으로 만들어(기수는 지움) 속도에 맞춰 재생, 정지 시 서 있는 말
- **영수증 이미지** — `지불` 후 PNG 생성, 공유/저장
- **레트로 디자인** — 7-세그먼트(DSEG7) 숫자, LCD 스캔라인, 파스텔 버튼

## 버튼

| 버튼 | 기능 |
|---|---|
| 빈차 / 주행 / 지불 | 초기화 / 출발 / 도착·영수증 |
| 할증 | 시계외 할증 +20% |
| 복합 | 모의주행(데모) — 운전 없이 테스트 |
| 호출 + 숫자 | 호출요금 입력 |
| 소리 · 화면 · 정보 · 인쇄 | 효과음 · 화면 꺼짐 방지 · 요금표 · 영수증 다시 보기 |

## 아이폰에 설치

1. Safari로 위 주소 접속 → 위치 권한 허용
2. 공유 버튼 → **홈 화면에 추가**

> iOS는 화면이 잠기면 GPS를 멈춥니다. 주행 중엔 화면을 켜 두세요(주행 시 자동 꺼짐 방지).

## 로컬 실행

```bash
python -m http.server 8123
```
http://localhost:8123 접속 (위치 기능은 localhost 또는 HTTPS에서만 동작)

## 구조

```
index.html            화면 구성
style.css             레트로 미터기 디자인
app.js                요금 엔진 · GPS · 말 애니메이션 · 영수증
sw.js                 오프라인 캐시 (서비스 워커)
manifest.webmanifest  PWA 설정
icons/                앱 아이콘
img/                  달리는 말 프레임 (horse-01~11 달리기, horse-12 서 있기)
```
